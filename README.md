# Python Snake Game 🐍

A classic 2D Snake Game developed using Python and the `turtle` graphics library as part of my programming portfolio.

## Features ✨
- Smooth snake movement and directional controls.
- Randomly spawning food elements.
- Real-time score tracking system.
- Clean and beginner-friendly Python code.

## How to Play 🎮
1. Run the `snake-game.py` file using Python.
2. Use the arrow keys (`Up`, `Down`, `Left`, `Right`) to control the snake.
3. Eat the food to grow longer and increase your score!

## Tech Stack 🛠️
- **Language:** Python 3
- **Library:** `turtle`, `time`, `random`
